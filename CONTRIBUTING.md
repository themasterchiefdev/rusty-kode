# Contribution policy

This repository is maintained solely by its owner, Rajiv Yanamandra. External code contributions and pull requests are not accepted.

You may fork the repository as permitted by the GPL-3.0-or-later license, but changes intended for this upstream repository must be authored and submitted by the owner.

Owner changes use a feature branch and pull request into `main`. Formatting, Clippy, tests, and package validation must pass before merge.

Please do not report security vulnerabilities in public issues. Follow [`SECURITY.md`](SECURITY.md) instead.
