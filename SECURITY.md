# Security policy

## Supported versions

`rusty-kode` is pre-release software. Only the latest revision on the default branch is considered for security fixes.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue or pull request.

Use the repository's **Security** tab, open **Advisories**, and select **Report a vulnerability**. Include reproduction steps, affected revisions, expected impact, and any suggested mitigation. Reports will be reviewed privately by the repository owner.
